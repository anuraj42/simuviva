About Simuviva

Simuviva is a innovative, self-study web applications designed to revolutionize how students prepare for viva-voce examination.
Traditional viva preparation often causes high anxiety and lacks realistic,adaptive practice.
Simuviva solves this by simulating a real-world examination environment where an intelligent,human-like AI avatar acts as an external professor.

Unlike static quiz applications, Simuiva utilizes advanced Large Language Models(LLMs) via API to mimic a professor's behaviour.
It features coversational branching logic evaluating a student's response in real time and dynamic generating follow-up questions
based on their answers.If a student answers well, the system increases the difficulty; if they struggle, it asks simpler, probing
questions to guide them.


Designed to be completely student-centric, users can independently select their graduation course(e.g., BCA, B.COM, BSC, etc.)
and specific technical Systems(e.g., Java, Python, Operating System). The system leverages the AI's internal knowledge base,
requiring zero manual question entry from educators. Built using a lightweight, responsive tech stack- HTML/CSS/JS for the
frontend, Python Flask for the backend, and SQLite for data tracking-


SimuViva offers a seamless, cross-platform experience, optimized for both laptops and mobile devices.

Key Highlights

  • Adaptive AI Examiner: Mimics realistic professor behaviors, cross-questioning students based on their previous answers.

  • Zero-Data Entry: Dynamically scales across multiple graduation courses and subjects using AI context injection.


  • Immersive Human Simulation: Features a dedicated visual avatar interface to replicate the psychological atmosphere of a real exam.

  • Offline-Ready Architecture: Lightweight design utilizing SQLite for efficient local data and history management.
